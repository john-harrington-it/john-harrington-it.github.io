01 About

I'm a systems engineer with 15+ years running enterprise infrastructure for law firms and financial-services organizations.

M365 User Lifecycle

Joiner and leaver automation driven by CSV, built on the Microsoft Graph PowerShell SDK. It creates users, licenses them through groups, and sets groups, manager, and mailbox settings. For leavers it blocks sign-in, revokes sessions, converts to a shared mailbox, sets an auto-reply, hands off OneDrive, and removes licenses. It's a dry run by default, safe to re-run, and won't remove a license until the mailbox is shared.
